# おやすみプランの時刻設定

入眠準備画面の設定を「寝る時間（ベッドに入る時間）」「ねむりと話す時間」「起きる時間」の順に配置した。

- 寝る時間は時刻入力で、初期値は 22:30。
- ねむりと話す時間は既存のタイマーの長さを選ぶスライダーで、15〜90分を15分刻みで選べる。初期値は30分。
- 起きる時間は時刻入力で、初期値は 07:00。朝を表すアイコンを追加した。
- 3項目ともこの端末のローカルストレージに保存し、再読み込み後も反映する。以前の保存データに起床時刻がない場合は 07:00 を補う。
- 時刻は目安。会話、起床アラーム、通知は未実装であることを画面にも明記した。
- PWA のキャッシュ名を `nemuri-shell-v2` に更新した。

確認: `node --check astro-site/public/app.js` と `npm.cmd run build` が成功。Edge のモバイル表示 320px・393px・430px で横はみ出しなし、下部メニューが画面下に固定されることを確認。22:30→23:15、30分→45分、07:00→06:45 に変更して再読み込み後も同じ値が残ることを確認した。
