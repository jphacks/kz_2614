# 名称変更と Android の追加案内

## 作業再開時の状態

前回の作業はコミット前で、名称変更、画像ファイルの改名、画面確認まで進んでいた。今回その変更を引き継ぎ、Android のインストール案内が出ない条件を修正した。

## 変更内容

- アプリ内の表示名を「ねむり」から「ねんぎつね」に統一。ヘッダー、各画面、ダイアリー、案内、通知文、英語表記、ブラウザーのタイトル、PWA の名称と説明、代替テキストを更新した。
- 画像に文字は含まれていないため絵柄は維持し、配信ファイル名を `nengitsune-*` に改名した。
- PWA の識別子 `/` は維持した。保存済み設定とダイアリーは旧 `nemuri-ui` から新 `nengitsune-ui` に読み込める。旧 Service Worker のキャッシュを新バージョンの有効化時に削除する。
- Docker Compose のプロジェクト名 `jphacks2026-nemuri` は既存 CT のコンテナーを別プロジェクト扱いにしないため維持した。これは画面表示名ではない。
- Android のインストール案内は、`beforeinstallprompt` と `getInstalledRelatedApps` の両方が使えない場合でも初回表示するようにした。一度閉じても次のページ読み込みでは再表示する。ホーム画面起動やインストール済みと判定できる場合は隠す。
