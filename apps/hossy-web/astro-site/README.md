# ねんぎつね Web UI

ハッカソン向けの、スマートフォンで使うことを想定した「ねんぎつね」アプリの UI プロトタイプです。やさしい横向きまくらロボットを主役に、ホーム、おやすみダイアリー、入眠準備、サウンド選択、製品紹介の画面を用意しています。

## 起動

Node.js 22.22.0 以上を使用します。

```powershell
npm.cmd install
npm.cmd run dev
```

`http://localhost:4321` を開きます。ビルドの確認は `npm.cmd run build` です。

## 現在の操作

- 下部メニューでホーム、ダイアリー、入眠準備、サウンドを切り替えられます。製品紹介は左上のアイコンから開けます。
- URL の `#diary`、`#diary-calendar`、`#routine`、`#sounds`、`#about` から各画面を直接開くこともできます。
- ダイアリーは日別タイムラインと月間カレンダーを切り替えられます。ラベンダー色の印がある日は記録を見られます。
- 入眠準備画面でベッドに入る時間、ねんぎつねと話す時間の長さ、起きる時間を設定できます。話す時間の長さを使って画面内のタイマーを開始・終了でき、タイマーの開始・終了時刻はダイアリーに記録されます。時刻の設定は目安で、アラームや会話機能はまだありません。
- サウンドを選ぶと、ホームと入眠準備画面の表示が変わります。
- 選択内容、進行中のタイマー、終了したタイマーの記録は、このブラウザのローカルストレージに保存されます。

## ホーム画面への追加

このサイトは PWA としてインストールできます。スマートフォンのブラウザで開くと追加案内のポップアップを表示します。Android でブラウザのインストール通知が利用できるときはボタンからインストールし、通知がない場合はボタンからブラウザメニューの追加手順を確認できます。iPhone では Safari の共有メニューから「ホーム画面に追加」を選びます。iPhone は Safari 上からインストール済みか判定できないため、追加済みでも Safari のタブから開いた場合は案内が表示されることがあります。案内は閉じるとそのページでは隠れ、次の読み込み時には再び表示します。ホーム画面から起動したときは表示しません。

公開環境で PWA をインストールするには HTTPS が必要です。`localhost` と `127.0.0.1` はローカル検証用の例外です。インストール後は、開いたことのある画面を通信できないときにも表示できます。タイマーの記録は端末内に保存され、特に iPhone では Safari とホーム画面版で保存領域が別になる場合があります。

ダイアリーの寝返りや睡眠中のようすは、画面イメージ用の**サンプル記録**です。現段階の実記録はブラウザ内タイマーの開始・終了時刻だけです。ロボット本体との接続、睡眠状態の測定、音声の再生、通知の配信は実装していません。
