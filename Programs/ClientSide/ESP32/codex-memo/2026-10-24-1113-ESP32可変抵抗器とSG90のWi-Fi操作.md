# ESP32 可変抵抗器と SG90 の Wi-Fi 操作

作成日: 2026-10-24 11:13 JST

## 作成したもの

- `ESP32-Reader/ESP32-Reader.ino`: GPIO34 の可変抵抗器を読み、HTTP で角度を送信。
- `ESP32-Follower/ESP32-Follower.ino`: GPIO18 に 50 Hz PWM を出し、SG90 を操作。HTTP API を提供。
- 各フォルダの `WiFiConfig.h`: 後から SSID とパスワードを設定する場所。
- `README.md`: 配線、Arduino IDE の操作手順、API 使用例。

## 設計

- 対象は従来の ESP32 DevKitC / ESP32 Dev Module。Reader の GPIO34 は ADC1、Follower の GPIO18 は PWM 出力。
- 角度指令は 0～150 度、PWM は 50 Hz / 1000～2000 µs、初期角度は 75 度。実機ごとの可動範囲に応じて調整する。
- Follower は `esp32-servo.local` を mDNS で通知。使えないネットワークでは Reader の `RECEIVER_IP` に Follower の IP を設定する。
- `POST /api/angle` で API モードに入り、可変抵抗器の上書きを停止。`POST /api/mode` の `mode=teleop` で遠隔操作に戻す。
- サーボには別の 5 V 電源を使い、ESP32 と GND を共通化する。可変抵抗器は 3V3 と GND の間に接続。
