# ESP32 2台の Wi-Fi 再接続確認

日時: 2026-10-24 13:20 JST

## 確認した結果

- アクセスポイント有効化後、Reader（COM6）と Follower（COM7）が Wi-Fi に接続した。
- シリアル出力上の IP は Reader が `192.168.100.112`、Follower が `192.168.100.111`。DHCP のため今後変わり得る。
- Reader は `esp32-servo.local` を解決して Follower を発見した。
- Reader に初回の HTTP 成功応答だけを記録するログを追加し、再ビルド・COM6 への再書き込み・フラッシュのハッシュ照合に成功した。
- 再起動後の Reader のシリアル出力で `Teleop HTTP 200; angle: 0` を確認。Follower が Reader のテレオペ角度指令を受理したことを示す。

## 残る確認

- PC は ESP32 と別のネットワーク上のため、PC から Follower の API へ直接接続できなかった。`GET /api/status`、`POST /api/angle`、`POST /api/mode` は同じ LAN に接続した端末から試す。
- 可変抵抗器を回した際の角度変化、SG90 の配線と軸の実際の動きは目視できていない。
- 今回の指令角度 0° だけでは、可変抵抗器の配線状態を判定できない。

Wi-Fi パスワードはこのメモに記載しない。
