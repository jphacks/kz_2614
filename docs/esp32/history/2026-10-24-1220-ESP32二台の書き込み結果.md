# ESP32 2 台の書き込み結果

日時: 2026-10-24 12:20 JST

## 実施結果

- 接続ポートは COM6 と COM7。esptool で両方とも ESP32-D0WD-V3 と識別。
- Arduino CLI 1.5.2-rc.1 と Espressif ESP32 ボードパッケージ 3.3.12 を作業フォルダ内に導入。
- Reader と Follower のビルドが成功。
- **COM6 = Reader、COM7 = Follower** として書き込み、両方で `Hash of data verified` を確認。
- 提供された Wi-Fi 情報を両方のローカル `WiFiConfig.h` に設定。パスワードはこのメモに記載しない。

## 起動後の確認

- 両方のシリアル出力で `Wi-Fi disconnect reason: 201` と `36` を確認。Espressif の定義で 201 は `NO_AP_FOUND`、36 は `STA_LEAVING`。
- 両方とも Wi-Fi の IP アドレスを取得していない。このため HTTP API、2 台間通信、可変抵抗器と SG90 の実動作はまだ確認できていない。
- コードを更新し、自動再接続と切断理由の出力を加えてから再ビルド・再書き込み済み。

## 環境上の注意

- `C:\〇Codex-JPHACK2026esp32` の `〇` を含むパスでビルドすると、ESP32 のリンカが標準ライブラリを見つけられなかった。`subst X: C:\〇Codex-JPHACK2026esp32` のドライブ別名でビルド・書き込みに成功。
- `.tools`、`.arduino-data`、`.arduino-downloads`、`.build` は `.gitignore` に登録済み。
- 書き込み後、約 1.9 GiB の一時ダウンロードと Arduino CLI の ZIP は削除。導入済みの CLI・ESP32 コアとビルドログは保持。
- ビルド・書き込みログは `.build/reader-compile.log`、`.build/follower-compile.log`、`.build/reader-upload.log`、`.build/follower-upload.log`。
