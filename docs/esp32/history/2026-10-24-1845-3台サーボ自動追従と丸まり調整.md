# 3台サーボの自動追従と丸まり調整

2026-10-24。FollowerのGPIO18・19・21に接続したSG90 3台へ、Readerの可変抵抗器から同じPWM幅を送る。Readerの0～180°指令を各関節の約60°の変化に分ける基本設定は、保存済みの全可動範囲600～2400 µsを使い、0°・90°・180°指令で3ピンそれぞれ1200・1500・1800 µs。中立1500 µsでは、ユーザーが最後のリンクを約90°と確認済み。180°側はリンクが伸び、異常なしとの報告。

ユーザーは0°側をさらに丸くしたいと希望。Followerに、0°側だけ50 µsずつ小さくする`5`、戻す`6`、不揮発メモリへ保存する`s`を実装。0°側への追加分は90°で0 µsとなるよう補間し、180°側は変えない。起動時は3台を1500 µsへ置き、Wi-Fi接続後は`t`コマンドなしでReaderへ自動追従するようにした。`n`で中立固定、`t`で追従再開できる。

ESP32 core 3.3.12でビルド成功。FollowerのCOM6（MAC末尾40:18）へ書き込み、フラッシュのハッシュ照合に成功。再起動後に手動開始コマンドなしでReaderの180°指令を受け、3ピンとも約1802 µsをGPIO入力読み取りで確認した。つまみを0°側へ動かした後、調整前は3ピンとも約1201～1202 µs。`5`を1回送ると1150 µs指令、3ピンとも約1152 µs。ユーザーは前より丸くなり、異音・突き当たり・発熱・リンク同士の接触なしと確認。さらに`5`を1回送ると1100 µs指令、3ピンとも約1101～1102 µs。ユーザーはさらに丸くなり、異常なしと確認した。

計100 µsの追加調整を`s`で保存し、`Servo settings saved`を確認。同じスケッチを再アップロードしてESP32を再起動し、フラッシュ照合が成功。再起動後に`v`で保存済みの全可動範囲600～2400 µs、丸まり調整100 µs、Readerの0°指令、3ピンの約1101～1102 µsを確認した。開始コマンドは送っていない。0°側の名目上の各関節角は約50°で、実際の先端角度0～180°の精度は測っていない。GPIO入力読み取りはサーボ端子での波形測定ではない。3台同時動作中の電池電圧と電流も未測定。

Arduino IDEから調整するときはFollowerのシリアルモニタを115200 bpsで開き、`v`で確認する。丸まりを増やす場合は軸とリンクを見ながら`5`を1文字ずつ送り、異音・突き当たり・発熱・接触があれば`6`で戻す。現在のコードは追加調整を最大150 µsに制限する。実機で良い位置になったら`s`で保存する。配線とAPIの詳細は`README.md`を参照。
