# 3台のSG90を同じ角度で連動

2026-10-24。ユーザーは可変抵抗器でSG90 3台を同じ方向へ動かし、直列の3関節がそれぞれ約1/3ずつ回って最後のリンクが約0～180°を向くよう希望。3台の回転は同じ向きに加算され、中立時に最後のリンクは約90°、動作試験の周囲と電源は準備済みとユーザーが回答した。

Readerの0～180°指令を最後のリンクの目標角とし、各サーボの名目角を`60° + 目標角/3`にした。0/90/180°目標は各軸60/90/120°に相当。Followerに保存済みの全可動範囲600～2400 µsの中央1/3を使い、3ピンに同じ1200～1800 µsを出す。中立1500 µsで起動し、シリアル`t`またはAPIの`mode=teleop`で3台の連動を開始、`n`または`mode=neutral`で中立へ戻す。`POST /api/angle`も3台共通の最後のリンク目標角として扱う。GPIO18・19・21の3台すべてを更新する。Readerのコード・配線・Wi-Fi設定は変更していない。

Arduino ESP32 core 3.3.12でFollowerのビルド成功。シリアル応答でCOM6がFollowerと再確認し、COM6への書き込み・フラッシュハッシュ照合成功。再起動直後はGPIO18・19・21すべて約1502～1503 µs。シリアル`t`でテレオペに切り替え、Readerからの目標132°で3ピンとも約1641 µs、可変抵抗器の下限で目標0°・3ピンとも約1201 µsをESP32端子の入力回路で確認した。上限側と最後のリンクの実測可動域・異音はユーザーの実機観察待ち。接続した3台の電源電圧・電流も未測定。

約0～180°はリンク中立を90°として3関節の回転量が加算される場合の名目上の目標。個体差・ホーン角・組み付けにより先端の実際の端点は変わるため、ユーザー観察に応じて共通のパルス範囲や各軸のオフセットを調整する。
