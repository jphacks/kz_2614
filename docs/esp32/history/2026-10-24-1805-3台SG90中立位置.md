# SG90 3台の中立位置

2026-10-24。ユーザーの指定はSG90を合計3台に増やし、まず全台のサーボホーンの中立位置を知ること。テレオペレーションは後でよいとのこと。

Followerの信号出力をGPIO18・GPIO19・GPIO21にした。起動時は3ピンとも50 Hz、HIGH時間1500 µsで、`neutral`モードを既定にする。このモードではReaderのテレオペと角度APIをHTTP 409で拒否する。GPIO19・21は現時点で1500 µs固定。GPIO18の既存のテレオペ/API経路と保存済みの調整値600～2400 µsは残し、将来シリアル`t`またはAPIの`mode=teleop`で再開できる。シリアル`n`またはAPIの`mode=neutral`で再び中立に戻せる。Readerのスケッチは変更していない。

Arduino ESP32 core 3.3.12でFollowerのビルド成功。USBのCOM番号が前回から変わり、シリアル`v`の応答でReader=COM9、Follower=COM6と判別。FollowerをCOM6へ書き込み、フラッシュのハッシュ照合に成功した。再起動後、Followerの`v`で1台目は90°/1500 µs、GPIO18・19・21のESP32端子上のHIGH時間は約1503・1503・1502 µs。しばらく後も約1502 µsで中立を保持し、`n`コマンド後にも3ピンの中立を確認した。これは端子の入力回路による読み取りで、サーボコネクタ側の波形測定ではない。軸の中立位置は後からユーザーが目視で確認した。

SG90 3台の赤線は十分な電流を供給できる別の4.8～6 V電源へ、茶/黒線は電源GNDとFollowerのGNDへ共通接続する。ユーザーは追加の2台を接続し、3台とも実物で中立位置になったと報告した。3台へ接続した状態の電池電圧・電流と各軸の正確な角度は未測定。ホーン取り付けは無通電で配線・取り外しを行い、ホーンなしで通電して中立位置へ移動させた後、電源を切って軸を回さないように装着する。1500 µsは電気的な中立で、3個体の機械的な正確な90°を保証するものではない。
