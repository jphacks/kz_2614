# デモと公開前の確認

今回の通しデモは [MVP.mdの体験とAC-01〜07](../MVP.md) に従います。指定操作者・1会話・1固定人形で「スマホ会話→明示要求の有限トントン→独立停止→利用記録」を確認します。既存公開認証を維持し、限定実機試験と公開多人サービスの合格を区別します。停止フェンス契約・実装・試験は未完了で、旧機器への開始を有効化しません。

## PC音声の再現

1. [セットアップ](setup/server.md) を完了し、LM StudioとSTT/TTSのモデルを用意する。このPCの既存環境は [local-pc.md](setup/local-pc.md) を参照する。
2. ルートで `./service-local.sh start` を実行し、PC上で `http://127.0.0.1:8765/` を開く。
3. 使用するマイクを選び、会話を開始する。話している途中の文字、返答テキスト、音声出力を確認する。
4. 返答中に話しかけ、新しい発話へ切り替わることを確認する。
5. 終了操作でマイクと会話を停止する。

Web上の表示だけで物理スピーカーの聴感を確認済みとしない。モデルの初回ロードや環境によって応答時間は変わる。

対象は [公開製品Web](https://hiroron-jphacks2026.hiroron.net/) と [ダイアリー入口（#diary）](https://hiroron-jphacks2026.hiroron.net/#diary)。2026-10-25の未ログイン確認はhiroron Passportのログイン画面までです。ログイン操作、製品UI本文、音声API到達、音声往復は今回実施していません。共有音声クライアントのAPI呼出しは製品画面へ接続済みですが、8765番の管理Webでの過去の成功を公開製品Webの合格に転記しません。

本人識別・人形所有権・BLE・接触センサー・AI/他者モードは実API未実装のため待ち状態とし、disabled表示から成功判定を行いません。ESP32操作は別の実機受け入れで確認します。
