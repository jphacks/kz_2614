# Chrome標準のPWAインストール画面について

ユーザーのAndroid Chrome通常タブでは、ページ内の紫色の案内は表示されても、Chrome標準のインストール確認画面は表示されなかった。同じ端末のシークレットタブでは紫色の案内が表示された。別の端末でも紫色の案内は表示されたが、追加方法の説明だけだった。

ページ内の紫色の案内はアプリ独自のUIであり、Chrome標準の画面ではない。Chrome標準の画面をページ側から開くには、Chromeが `beforeinstallprompt` を発火した後、ユーザーの操作で保存したイベントの `prompt()` を呼ぶ必要がある。イベントが来ない場合は、ページから標準画面を強制表示できない。

公開サイトは未認証のアクセスに401を返す。マニフェストも認証が必要な場合、`<link rel="manifest">` に `crossorigin="use-credentials"` が必要なので追加した。これによりChromeが認証情報付きでマニフェストを取得できる構成にした。通常タブだけ紫色の案内を隠す可能性があった「インストール済み関連アプリ」の判定を表示条件から外した。スクリプトURLにバージョンを付け、Service Workerのキャッシュ名を更新した。

確認結果: `npm.cmd run build`、`node --check astro-site/public/app.js`、`git diff --check` は成功。生成されたHTMLに認証付きマニフェストとバージョン付きスクリプトが含まれることを確認した。Android Chromeでマニフェストとアイコンが読み込まれること、紫色の案内のボタンが「Chromeでインストール」に変わり、押すとChrome標準の確認画面が開くことは、公開環境の認証の内側と実機で別途確認が必要。

参考: https://web.dev/articles/add-manifest / https://developer.chrome.com/docs/lighthouse/pwa/installable-manifest/
