# ねむり UI 制作メモ

作成日時: 2026-10-21 19:02（日本時間）

## 方向性

ハッカソンの「ねむり」イメージ画像から、やさしい横向きまくらロボット、星や月、淡いラベンダーとピンクの色を採用した。LOVOT アプリの参考画像から、中央にロボットを置く構成、上部のシンプルな操作、下部のタブメニューを取り入れた。画像をそのまま転載せず、UI 用のロボット画像を新たに制作した。

配色はユーザーの確認によりラベンダーを基調とする。「青売り」は「アプリ」の誤変換であり、青寄りの配色指定ではない。

## 実装

- `astro-site/src/pages/index.astro`: ホーム、入眠準備、サウンド、製品紹介の4画面。
- `astro-site/src/styles/app.css`: スマートフォンを優先した画面幅、カード、色、下部ナビゲーション、セーフエリア対応。
- `astro-site/public/app.js`: タブ切り替え、サウンド選択、時間設定、画面内タイマー、ローカル保存。
- `astro-site/public/nemuri-plush.png`: ねむりのオリジナル画像。
- `astro-site/README.md`: 起動方法と現段階の動作範囲。

## 確認

- `npm.cmd run build` 成功。
- Chrome のヘッドレス表示でホーム、入眠準備、サウンド画面を確認。顔がステータス欄に隠れないよう画像位置を調整した。
- 最終プレビュー画像: `ねむり_UIプレビュー.png`、`ねむり_入眠準備.png`、`ねむり_サウンド.png`。

## 現段階

UI プロトタイプのため、ロボット本体との接続、音声再生、通知配信は未実装。音の選択と入眠タイマーはブラウザ内で動く。
