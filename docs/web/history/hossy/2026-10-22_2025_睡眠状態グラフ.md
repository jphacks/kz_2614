# 睡眠状態グラフの追加

- ダイアリーの日別表示に、中央線から左右へ伸びる時間別グラフを追加した。左のピンクは「眠りが浅い」、右のラベンダーは「よく眠れた」を示す。
- グラフの値は画面イメージ用のサンプル。タイマーで実際に記録できるのは開始・終了時刻のみなので、その日にはグラフを出さず「未計測」と表示する。
- サンプル記録の日付を切り替えると、夜の開始時刻に合わせたグラフに変わる。
- `npm.cmd run build` 成功。393 × 852 px のブラウザ確認で画面の横スクロールなし、棒は中央線から意図した方向へ伸びた。実記録日の棒は 0 本で「未計測」と表示された。
- 表示確認画像: [睡眠グラフプレビュー](2026-10-22_2024_睡眠グラフプレビュー.png)
- 公開 CT では更新後に `git pull`、`docker compose up -d --build` を実行する。
