# おやすみカード全体の操作

「今夜のねんぎつね」にある紫色の「ねんぎつねとおやすみしよう」カード全体をボタンに変更した。カード内の月、文字、矢印、余白を押したときに、既存の `data-go="routine"` により同じ準備画面へ進む。矢印は装飾の `span` にし、ボタンの入れ子を避けた。キーボードのフォーカスとEnter/Space操作には標準のボタン動作を使う。

カードの幅、枠線、文字揃えと押下時の反応をCSSで調整し、従来の見た目を維持した。

確認: `npm.cmd run build` 成功、`git diff --check` 成功。実機の公開サイトはCTでの再ビルド後に確認する。
