# Docker 公開準備

- リポジトリのルートに `compose.yaml` を追加。`docker compose up -d` で Astro サイトをビルドして配信する。
- `astro-site/Dockerfile` で Astro の静的ファイルをビルドし、Nginx で配信する。
- `pull_policy: build` により、サーバーで `git pull` 後に同じ `docker compose up -d` を実行すれば更新が反映される。
- 既定の公開ポートは TCP 80。サーバー固有の `.env` で `HTTP_PORT` を変更できる。
- 起動・更新・確認手順は `DEPLOY.md` に記載。
- `docker compose config` は既定の 80 番と `HTTP_PORT=8080` の両方で正常。`npm.cmd run build` も成功。
- 手元の Windows には Docker CLI/Compose があるが Docker デーモンは起動していないため、コンテナのビルド・起動は未検証。Ubuntu CT での初回起動時に `docker compose ps` と HTTP 応答を確認する。
