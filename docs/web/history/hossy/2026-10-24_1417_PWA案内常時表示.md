# PWA インストール案内の表示修正

- 公開サイトでは `/manifest.json`、`/sw.js`、アイコン、`/app.js` が 200 で配信されていた。案内が出ない原因は、Android で `beforeinstallprompt` が発火した場合にしかバナーを出さない条件だった。
- スマホのブラウザでは、ホーム以外の画面も含めて追加案内のポップアップを表示するよう変更した。Android でインストール通知が来た場合はブラウザのインストール画面を開き、来ない場合はブラウザメニューから追加する手順を表示する。
- Android の対応ブラウザでは `getInstalledRelatedApps()` で同じ PWA がインストール済みか確認する。ホーム画面からの起動時は従来どおり案内を隠す。閉じた案内はそのタブ内で再表示しない。
- `npm.cmd run build` 成功。Edge の 393 × 852 px モバイル表示で、インストール通知を模擬的に止めてもダイアリーに案内が出ること、手順が開くこと、インストール済み判定では隠れること、横スクロールがないことを確認。インストール条件エラーは 0 件。

- 実際のスマホでのインストール操作は、CT の更新後に確認が必要。
