# PWAアイコンとローディング画面・メイン画像の改善

作成日時: 2026-10-24 16:43（日本時間）

## 変更内容

- `images/nen_icon.jpg` から PWA・ホーム画面追加用アイコンを生成し、`astro-site/public/icons/nengitsune-192.png`（192×192）、`nengitsune-512.png`（512×512）、および Android のアダプティブアイコン／スプラッシュ表示で見切れない余白付きの `nengitsune-maskable-512.png`（512×512、`purpose: "maskable"`）を配置した。
- `astro-site/public/manifest.json` の `background_color` を画像背景と同一の `#17213a` に設定し、Android Chrome のシステム起動スプラッシュからアプリ内ローディング画面へ継ぎ目なくつながるようにした。
- `images/nen_loading.jpg` を `astro-site/public/nengitsune-loading.jpg` として配置し、`Layout.astro` の `apple-touch-startup-image` に設定するとともに、起動時に表示して自動でフェードアウトするローディング画面（`#loading-screen`、タップで即時スキップ可）を追加した。ローディング完了時に `<meta name="theme-color">` を `#17213a` から `#f7f5fc` に切り替える。
- `images/nen_gitune.jpg` を `astro-site/public/nengitsune.jpg` として配置し、ホーム画面・入眠準備画面・製品紹介画面のメイン画像を差し替えた。カードの背景色を夜空の `#152036` に合わせて調整し、不要になった旧 `nengitsune-plush.png` を削除した。
- Service Worker（`astro-site/public/sw.js`）のキャッシュ名を `nengitsune-shell-v4` に更新し、新しいアイコンとローディング画像・メイン画像をプリキャッシュ対象に含めた。

## 確認

- `node --check astro-site/public/app.js`、`npm.cmd --prefix astro-site run build`、`git diff --check` が成功。
- Chrome ヘッドレスのモバイル表示（幅 320px・393px・430px）で全5画面（ホーム、入眠準備、製品紹介、ダイアリー、サウンド）に横スクロールが発生しないことを確認。
- 起動直後のローディング画面表示と、フェードアウト後のホーム画面・入眠準備画面への遷移を確認。
