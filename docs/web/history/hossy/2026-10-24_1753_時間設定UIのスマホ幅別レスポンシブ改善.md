# 時間設定UIのスマホ幅別レスポンシブ改善

作成日時: 2026-10-24 17:53（日本時間）

## 変更内容

- 入眠準備画面（`#screen-routine`）の「おやすみプラン」カード（`.settings-card`）がスマートフォンの画面幅やOS標準の `<input type="time">` 表示形式（`午前/午後` 表記やOS固有の余白・時計アイコン）に左右されず、どの画面幅でもきれいに整列するよう改善した。
- 「寝る時間」「起きる時間」をカスタム表示ピル（`.time-field`：`#bedtime-display` / `#wake-time-display` + 時計SVGアイコン）の上に透明な `<input type="time">` を重ねる構成に変更した。これにより表示幅とデザインを全機種で統一しつつ、タップ時には従来どおりOS標準の時刻ピッカーが開く。
- CSS Grid と `clamp()` を用いて、カードの余白・アイコンサイズ・文字サイズ・右端の値ボックス（`22:30` / `30分` / `07:00`）の幅（`clamp(86px, 24vw, 104px)`）がスマホの画面幅に応じて自動で伸縮し、3行の右端ピルが縦にぴたりと揃うようにした。
- 「ねんぎつねと話す時間」のスライダー下に、6段階のボタン（`15分`・`30分`・`45分`・`60分`・`75分`・`90分`）を6等分グリッド（`grid-template-columns: repeat(6, minmax(0, 1fr))`）で配置し、スライダー操作だけでなくボタンタップでも直接時間を選べるようにした。
- 320px などの小型端末でもヘッダータイトルやバナーの文字・画像が折り返したり重なったりしないよう `clamp()` で自動調整した。
- Service Worker（`astro-site/public/sw.js`）のキャッシュ名を `nengitsune-shell-v6`、スクリプト参照を `/app.js?v=20261024-4` に更新した。

## 確認

- `node --check astro-site/public/app.js`、`npm.cmd --prefix astro-site run build`、`git diff --check` が成功。
- Chrome ヘッドレスのモバイル表示で幅 320px（小型スマホ）・393px（標準スマホ）・430px（大型スマホ）を検証し、いずれも横スクロールなしで3行の値ピル幅（86px / 94px / 103px）と右端座標が1pxの狂いなく揃うことを確認。
