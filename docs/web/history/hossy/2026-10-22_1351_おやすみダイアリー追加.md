# おやすみダイアリー追加

作成日時: 2026-10-22 13:51（日本時間）

## 目的

LOVOT アプリのダイアリーを参考に、ねむりと過ごした夜を日付ごとに振り返る UI を追加した。既存のラベンダー基調のデザインに合わせた。

## 追加した画面と操作

- 下部メニューに「ダイアリー」を追加し、製品紹介は左上のアイコンから開ける構成にした。
- 「1日の記録」では選んだ日の概要と時刻順のタイムラインを表示する。前後の日付へ移動できる。
- 「カレンダー」では記録のある日を示し、日付を押すと日別画面に移る。
- タイマーの開始・終了時刻をブラウザのローカルストレージに保存し、ダイアリーに表示する。再読み込み後も残る。
- 寝返りや落ち着いた時間などのイベントはサンプル記録として明示した。実際に測定した睡眠データではない。

## 確認

- `node --check public/app.js` と `npm.cmd run build` が成功。
- Chrome のスマホ幅表示で日別・月間画面を確認した。プレビュー画像は `ねむり_ダイアリー日別.png` と `ねむり_ダイアリー月間.png`。
- 実ブラウザで、月間画面の表示、記録日の選択、タイマー終了後の2イベント表示、再読み込み後の保存を確認した。

## 今後の接続点

現在の実記録はタイマーの開始・終了時刻だけ。睡眠中の動きや状態を表示するには、センサーまたはねむり本体からのデータ連携が必要。
