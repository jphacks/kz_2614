# 夜空と星のUI配色統一と静かなエフェクト追加

作成日時: 2026-10-24 17:18（日本時間）

## 変更内容

- 「ねんぎつね」のイラスト（夜空の紺色背景・きつねと星のやさしい黄色）に合わせて、アプリ全体の配色を就寝前の暗い部屋でも目にやさしい**夜空の紺色（`#11192c`〜`#152036`〜`#1a2742`）× 星明かりの黄色（`#f5c85c`〜`#ffd875`）**に統一した。
- 文字色は真っ白ではなく温かみのある生成り色（`#faf3e3`）と落ち着いた夜霧ブルー（`#98a7c4`）を採用し、時間入力（`input[type="time"]`）も `color-scheme: dark` でダーク表示に統一した。
- ブラウザのステータスバー（`<meta name="theme-color">`）および `manifest.json` の `theme_color` / `background_color` を `#152036` に統一した。
- スマートフォンの負荷にならない軽量な静かなエフェクト（GPU合成される `transform` と `opacity` のみを使用）を追加した：
  - 背景でゆっくり瞬く小さな星明かり（`.ambient-sky` / `.sky-star`、5.2秒周期）。
  - 画面タブ切り替え時の穏やかなフェードイン（`screen-calm-in`、0.34秒）。
  - 画面タップ時にタップ位置から星明かりの波紋と小さな光の粒が静かに広がって消えるエフェクト（`#tap-layer` / `.tap-burst`、同時最大5個に制限）。
  - OSの「視差効果を減らす（`prefers-reduced-motion: reduce`）」設定が有効な端末ではエフェクトを自動で抑止する。
- Service Worker（`astro-site/public/sw.js`）のキャッシュ名を `nengitsune-shell-v5`、スクリプト参照を `/app.js?v=20261024-3` に更新した。
