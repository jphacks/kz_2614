# PWA 対応

- `manifest.json`、192/512 px のホーム画面アイコン、`sw.js` を追加した。インストール時は独立した画面として起動する。
- ホームの案内は、Android ではインストール可能イベントが来たとき、iPhone/iPad ではブラウザ表示中に出す。iPhone/iPad では Safari の共有メニューから追加する手順を表示する。ホーム画面から起動した画面では案内を隠す。
- 案内を閉じた場合は同じタブ内で再表示しない。キャッシュは通信可能なら新しいファイルを確認し、通信できない場合に保存した画面を使う。
- 本番ビルドをローカルプレビューで検証。Edge のインストール条件エラーは 0 件。サービスワーカーは activated、393 px 幅で横スクロールなし。オフラインでダイアリー、CSS、画像が開いた。iPhone の案内と手順表示、インストール済み判定による非表示、Android のインストール案内を確認した。
- [案内のプレビュー](2026-10-24_1348_PWA案内プレビュー.png)
- 公開環境でインストール機能を使うには HTTPS が必要。CT の IP アドレスへ直接 HTTP でアクセスした場合はインストール不可。実機でのインストール操作は未確認。
- iPhone の Safari タブからは、別のホーム画面版がインストール済みか判定できない。ホーム画面版の起動時には案内を隠し、Safari タブ上では案内を閉じられるようにした。
