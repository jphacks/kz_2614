# ねんぎつね 製品Webの使い方

対象は `apps/hossy-web` の製品UI/PWAです。[公開ホーム](https://hiroron-jphacks2026.hiroron.net/) / [ダイアリー](https://hiroron-jphacks2026.hiroron.net/#diary)。公開先はhiroron Passportの認証前画面まで確認しており、ログイン後のUIや配信版とソースの一致は未確認です。以下は2026-10-25時点のリポジトリ内コードに基づく手順です。

OneDev main `caf3541`へ同期済みです。起動時に新しいロゴのローディング画面を表示し、その後、夜空テーマのホームを開きます。ローディング画面はタップでもスキップできます。

## 入眠時間を記録する

1. ホームの「ねんぎつねとおやすみしよう」、または下部の「ねんぎつね」を開く。
2. 「寝る時間」「起きる時間」を目安として設定する。時刻になって自動開始したり、朝にアラームが鳴ったりする機能はない。
3. 「ねんぎつねと話す時間」をスライダーまたは15/30/45/60/75/90分のボタンから選ぶ。現状は会話を開始せず、選んだ長さのタイマーとして使う。
4. 「ねんぎつねとおやすみ」を押す。その場で開始し、ホームに残り時間が表示される。
5. 途中で終える場合は再び下部の「ねんぎつね」を開き、「おやすみ時間を終える」を押す。終了操作時刻までが記録される。
6. 設定時間を過ぎると、画面の次の更新で期限時刻を終了として記録する。再読込後も開始時刻から計算し直す。画面を閉じたままの通知・アラームはない。

実行中に時間設定を変えると、元の開始時刻からの期限も変わります。短縮によって期限を過ぎれば自動終了します。記録を取りたい長さに合わせて設定してください。

## ダイアリーを読む

下部の「ダイアリー」から「1日の記録」と「カレンダー」を切り替えます。日別の矢印で前後の日、月間の矢印で前後の月へ移動し、日付を押すと日別へ戻ります。未来の日付は選べません。

- 「このブラウザの記録」は終了したタイマーの開始/終了時刻、合計時間、回数。最大100件で、日をまたいだタイマーは開始日にまとまる。
- 「サンプル記録」「サンプル表示」の睡眠状態・寝返り・グラフは画面イメージで、センサー計測ではない。カレンダーの `●` は実記録、`✦` はサンプル。
- 記録がない日は「記録なし」。同じ日に実記録があるとサンプルより優先し、眠りのようすは「未計測」になる。進行中タイマーは終了まで日記に追加されない。

記録の編集・削除・書き出し、端末間同期はありません。

## サウンドと製品紹介

「サウンド」で4種類から1つ選ぶと、ホームと入眠準備の名前が変わります。音は再生しません。ヘッダーの製品紹介ボタンから説明画面へ進めます。お知らせボタンは定型メッセージを表示します。

## 保存とホーム画面追加

設定・進行中タイマー・終了記録は、この端末/ブラウザー/配信元のlocalStorageに保存します。同じアカウントで別端末にログインしても同期しません。URLのscheme/host/portやブラウザーを変えると保存領域が変わり、サイトデータ消去で失われます。保存できない環境でも操作は続くため、重要な記録が保持されたかは再読込後にも確認してください。複数タブの同時操作では状態が上書きされる場合があります。

モバイルでは追加案内を開き、Android等でインストールボタンが出る場合は標準画面を使います。出ない場合はブラウザーのメニュー、iPhone/iPadはSafariの共有→「ホーム画面に追加」を使います。HTTPSまたはlocalhostでSWが正常登録・資産保存できた場合、通信できないときにキャッシュを利用します。実端末のインストール・認証後のオフライン動作は未確認です。

## 音声会話を確認する場合

この製品Webには音声会話・サウンド再生・ESP32接続がありません。PCの `http://127.0.0.1:8765/` は別の音声・設定管理Webです。公開HTTPSからPCのHTTPへ直接つなぐ前提にはせず、担当者と既存の接続経路を確認してから [結合テスト表](../demo.md#公開製品webの結合テスト準備) に沿って進めます。
