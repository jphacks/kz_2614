# ねんぎつね 製品Webの使い方

[公開ホーム](https://hiroron-jphacks2026.hiroron.net/) / [ダイアリー](https://hiroron-jphacks2026.hiroron.net/#diary)。この手順はリポジトリの音声接続MVPに基づきます。公開先は認証前までの確認で、公開版とソースの一致やログイン後の音声接続は未確認です。[起動・接続設定](../setup/hossy-web.md)。

## 会話を始めて終える

1. ホームの案内または下部「ねんぎつね」から準備画面へ進む。
2. 寝る/起きる時刻を目安として設定し、話す長さを15〜90分の15分刻みで選ぶ。時刻で自動開始せず、起床アラームも鳴らない。
3. 使用するマイクを確認して「会話を始める」を押し、ブラウザーのマイク許可に応じる。API未設定・認証エラーなら表示を確認する。無断で別のマイクへ切り替える前提にしない。
4. 音声処理の準備完了から時間を数える。途中の文字起こし、返答文字、返答音声を確認する。API状態が正常でも実際のモデル成功は最初の発話で確認する。
5. 終えるときは「会話を停止」を押す。端末音声停止とサーバー停止応答の結果をそれぞれ確認する。端末の開始/終了時刻と理由は日記へ保存される。

期限は開始時に固定され、途中の時間変更は次回から反映されます。画面非表示・画面を閉じる操作・音声エラー・別タブ開始でも停止します。戻る/再読込だけで再開せず、再開には開始操作が必要です。寝かせたままのバックグラウンド会話やアラーム用途には使いません。

## ダイアリーと保存

「ダイアリー」の「1日の記録」「カレンダー」を切り替えます。日付を押すと日別へ戻り、未来日は選べません。●は実記録、✦はサンプルです。

実記録は音声準備完了から端末停止までの時刻/理由で、睡眠測定ではありません。開始日の欄にまとまり、100件まで表示します。旧版のタイマー記録は旧記録として残ります。同日に実記録があればサンプルより優先し、睡眠は未計測、機器の動きは未連携です。サンプルの睡眠グラフ/寝返りを測定結果として扱いません。

設定と記録はこのブラウザーのlocalStorageへ別々に保存し、音声と会話本文は保存しません。保存できない場合は警告と未保存表示を確認してください。未保存分は再読込で失われ得ます。同一originの他タブの変更を取り込みますが、端末間同期・記録編集/書き出しはありません。サイトデータ消去や配信origin変更では保存が引き継がれません。

## サウンド・人形・PWA

サウンドの4種類は名前の選択で、音源の試聴/再生はありません。本人識別、人形の所有権、BLE/接触センサー、AI/他者モードは未接続で利用不可です。ブラウザーの会話だけで人形は動きません。

モバイルの案内から標準インストールUI、またはSafari共有→「ホーム画面に追加」を使います。オフラインでは保存済みの静的画面を表示できる場合がありますが、ログイン/API/音声会話はオフライン動作しません。PWA実端末は未検証です。
